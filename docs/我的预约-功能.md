# 我的预约 - 功能接口文档

## 功能概述
提供用户查看、取消、改签预约的功能,支持预约历史记录查询和状态跟踪。

## 接口列表

### 1. 获取我的预约列表
**接口地址**: `GET /api/appointments/my-list`

**请求参数**:
- `status` (可选): 预约状态筛选 (PENDING/CONFIRMED/COMPLETED/CANCELLED)
- `keyword` (可选): 搜索关键词(预约号/医生姓名)
- `pageNum` (可选): 页码,默认1
- `pageSize` (可选): 每页数量,默认10

**返回数据**:
```json
{
  "code": 200,
  "message": "成功",
  "data": {
    "total": 25,
    "pageNum": 1,
    "pageSize": 10,
    "list": [
      {
        "id": 1,
        "appointmentNo": "AP202605180001",
        "doctorName": "张医生",
        "doctorTitle": "主任医师",
        "departmentName": "心内科",
        "appointmentDate": "2026-05-20",
        "timeSlot": "MORNING",
        "timeSlotText": "上午",
        "status": "PENDING",
        "statusText": "待确认",
        "symptom": "胸闷气短",
        "createTime": "2026-05-18 10:30:00"
      }
    ]
  }
}
```

### 3. 取消预约
**接口地址**: `POST /api/appointments/{id}/cancel`

**路径参数**:
- `id`: 预约ID

**请求体**:
```json
{
  "cancelReason": "个人原因需要取消"
}
```

**返回数据**:
```json
{
  "code": 200,
  "message": "取消成功",
  "data": null
}
```

### 4. 改签预约
**接口地址**: `POST /api/appointments/{id}/reschedule`

**路径参数**:
- `id`: 原预约ID

**请求体**:
```json
{
  "newScheduleId": 15,
  "newAppointmentDate": "2026-05-22",
  "newTimeSlot": "AFTERNOON"
}
```

**返回数据**:
```json
{
  "code": 200,
  "message": "改签成功",
  "data": {
    "id": 2,
    "appointmentNo": "AP202605180002",
    "oldAppointmentId": 1
  }
}
```

### 5. 获取可改签的号源列表
**接口地址**: `GET /api/appointments/reschedule-schedules`

**请求参数**:
- `doctorId`: 医生ID
- `startDate`: 开始日期
- `endDate`: 结束日期

**返回数据**:
```json
{
  "code": 200,
  "message": "成功",
  "data": [
    {
      "id": 15,
      "doctorId": 5,
      "scheduleDate": "2026-05-22",
      "timeSlot": "AFTERNOON",
      "timeSlotText": "下午",
      "availableSlots": 8,
      "totalSlots": 20
    }
  ]
}
```

## 预约状态枚举

| 状态码 | 状态名称 | 说明 |
|--------|----------|------|
| PENDING | 待确认 | 预约已提交,等待医生确认 |
| CONFIRMED | 已确认 | 医生已确认预约 |
| COMPLETED | 已完成 | 就诊已完成 |
| CANCELLED | 已取消 | 预约已取消 |

## 时间段枚举

| 时间段码 | 显示文本 | 说明 |
|----------|----------|------|
| MORNING | 上午 | 08:00-12:00 |
| AFTERNOON | 下午 | 14:00-18:00 |
| EVENING | 晚上 | 19:00-21:00 |

## 错误码说明

| 错误码 | 说明 |
|--------|------|
| 400 | 请求参数错误 |
| 401 | 未登录或token失效 |
| 403 | 无权限操作 |
| 404 | 预约不存在 |
| 500 | 服务器内部错误 |
